# BackLounge 販売運用

この文書を、顧客管理システムの申込から納品までの運用基準とする。
振込先・ダウンロードURLなどの秘密情報は、このリポジトリには保存しない。

## 販売条件（基準）

| 項目 | 内容 |
| --- | --- |
| 商品 | 顧客管理システム（Windows向けダウンロード商品） |
| ライト版 | 19,800円（税込・買い切り） |
| スタンダード版 | 39,800円（税込・買い切り） |
| 申込方法 | 商品ページの「購入を申し込む」からフォーム送信 |
| 支払方法 | 銀行振込 |
| 振込期限 | 振込案内メールの送信日から7日以内 |
| 納品 | 入金確認後、ダウンロードURLをメールで案内 |
| 納品目安 | 通常1〜2営業日以内 |
| 返品・返金 | デジタル商品のため原則不可。不具合は修正版の提供で対応 |

## 対応フロー

1. 申込を受信したら、台帳に `申込受領` として記録する。
2. 申込内容（氏名、メール、希望プラン、金額）を確認する。
3. 振込案内メールを送り、台帳を `振込案内済み` に更新する。
4. 入金を確認したら、台帳に確認日を記録し、`入金確認済み` に更新する。
5. 納品メールでダウンロードURLと手順書を案内し、台帳を `納品済み` に更新する。
6. 不具合相談は `サポート対応中` として記録し、解決後に `完了` に更新する。
