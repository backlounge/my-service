# BackLounge 営業候補・市場反応

最終更新: 2026-08-05

## 現在の狙い

- 1〜2人で運営する個人サロン、美容室、整体院
- 紙カルテ・Excel・メモで顧客情報や来店履歴を管理している
- 多機能な月額POSやクラウドサービスまでは必要としていない
- Windows PCを使い、買い切り型を希望する

## 公開情報で確認できた需要

| 情報源 | 確認できた困りごと | 営業への利用 |
| --- | --- | --- |
| 厚生労働省「美容業向け デジタル化による生産性向上のすすめ」 | 紙・Excelのカルテは保管、更新、必要情報の取り出しが面倒 | 美容室向け投稿の根拠に使う |
| 個人まつげサロン運営者の公開記事 | 紙カルテの準備・管理が時間のロスで電子化した | 「紙を探す時間」を訴求する |
| 小型美容室の公開ブログ | 紙カルテとサロンボードを併用して顧客管理している | 複数管理の面倒を訴求する |
| 整体院向け各社の公開ページ | 紙・LINE・予約表への分散、最終来院日の未把握、休眠顧客フォロー不足を共通課題として提示 | 整体院向け投稿と商品説明に反映する |
| 個人サロン向けカルテテンプレート販売者の公開記事 | 「紙カルテを卒業してデータ保存したい」層を購入対象としている | 紙から小さく移行したい層が存在する根拠にする |
| 整体院向け比較記事・買い切りソフト各社 | 月額費用・多機能化が導入障壁になり、紙管理を続ける院がある | 「必要な機能だけ・月額なし」を主訴求にする |

## 除外した場所

| 場所 | 除外理由 |
| --- | --- |
| Facebook「美容の広場」 | 公開投稿の中心が美容室経営の実務ではなく、宣伝・自己啓発系。顧客管理検索でも有効な相談投稿を確認できなかった |
| Facebookの経営者交流・副業・ビジネスパートナー募集系グループ | 投稿数は多いが相互宣伝が中心で、購入見込みや信頼獲得につながりにくい |
| 女性限定・女性起業家グループ | BackLoungeページ名義での参加適合性が不明。規約を確認せず参加しない |

## 禁止事項

- 質問していない個人へ宣伝DMを送らない。
- グループ規約で宣伝禁止の場所へ商品リンクを投稿しない。
- 古いブログ記事だけを根拠に、現在も困っていると決めつけない。
- 医療機関向け電子カルテとして表示・販売しない。
