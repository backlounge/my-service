# BackLounge 販売方針

## 現在の販売対象

- 見積管理システム（24,800円・買い切り）
- 顧客管理システム（ライト版 19,800円／スタンダード版 39,800円・買い切り）

上記2商品は、どちらも販売中である。片方に限定せず、課題に応じて両方を販売する。

## 導線の原則

1. 各商品ページから、他の販売中商品も検討できるようにする。
2. すべての商品で、商品ページ → 購入申込フォーム → 受付メール → 振込案内 → 入金確認 → ZIP納品の流れを持つ。
3. ブログ・Facebook・コミュニティ投稿は、該当する商品ページへ直接つなぐ。
4. UTM付きURLを使い、アクセス解析でページ閲覧・申込画面表示・申込完了を確認する。

## 商品追加の条件

在庫管理・予約管理などを追加するときは、販売開始前に以下をそろえる。

- 実動する製品本体と、導入手順・動作環境
- 価格、対象者、含まれる機能・含まれない機能
- 商品ページ、画面イメージ、FAQ、購入申込導線
- 申込受付メール、振込案内、納品ZIP、テスト購入
- sitemap・構造化データ・アクセス解析への掲載

未完成の商品は「準備中」として要望受付にとどめ、販売中とは表示しない。
