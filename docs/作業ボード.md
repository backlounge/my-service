## 運用方法

1. 作業を始める時は、該当タスクを「今日やる」に置く。
2. 完了時は、確認結果を書いて「完了」へ移す。
3. 外部待ち・佐藤さん待ちは「待ち」に移す。止まっている理由を必ず書く。
4. 新しい依頼は、既存タスクと重複・矛盾しないか確認してから追加する。

佐藤さんは「作業ボード見て」「次を進めて」と言えばよい。優先順位づけ、状態更新、矛盾確認はCodexが行う。
